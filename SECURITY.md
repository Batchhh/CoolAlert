# Security Policy

## Supported versions

Security fixes are made on the latest release and `main`.

## Reporting a vulnerability

Please don't open a public issue for security problems. Instead, report them privately through [GitHub security advisories](https://github.com/Batchhh/CoolAlert/security/advisories/new). Include:

- a description of the issue and its impact
- steps or code to reproduce it
- the iOS and CoolAlert versions affected

You'll get a response within a few days, along with updates as the fix progresses.
